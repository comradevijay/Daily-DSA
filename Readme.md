# IBM Practice Problems 🚀

---

## 💡 Tips for Each Problem

1. Read the problem twice
2. Think of the logic before coding
3. Write logic as comments first, then convert to code
4. Use `return` instead of `print` inside functions
5. Test with the sample input given
6. Try an edge case (empty array, zero, negative number)

---

## 🟢 Level 1 — Very Easy

**1. Add Two Numbers**

- Input: `a=3, b=5`
- Output: `8`

**2. Find if a Number is Even or Odd**

- Input: `n=7`
- Output: `"Odd"`

**3. Return the Square of a Number**

- Input: `n=4`
- Output: `16`

**4. Find Maximum of Two Numbers**

- Input: `a=10, b=20`
- Output: `20`

**5. Count How Many Elements in a List**

- Input: `arr=[1,2,3,4]`
- Output: `4`

## 🟠 Level 3 — Medium Easy (IBM Exam Level)

**16. Find Second Largest in Array**

- Input: `arr=[3,1,4,1,5,9]`
- Output: `5`

**17. Remove Duplicates from Array**

- Input: `arr=[1,2,2,3,3,4]`
- Output: `[1,2,3,4]`

**18. Check if Number is Prime**

- Input: `n=7`
- Output: `"Prime"`

**19. Reverse an Array**

- Input: `arr=[1,2,3,4,5]`
- Output: `[5,4,3,2,1]`

**20. Find Most Frequent Element in Array**

- Input: `arr=[1,2,2,3,2]`
- Output: `2`

**21. Check if Two Strings are Anagrams**

- Input: `s1="listen", s2="silent"`
- Output: `"Yes"`

**22. Find All Prime Numbers from 1 to N**

- Input: `n=10`
- Output: `[2,3,5,7]`

**23. Sort Array in Ascending Order (without sort())**

- Input: `arr=[3,1,4,1,5]`
- Output: `[1,1,3,4,5]`

**24. Find Missing Number in Array 1 to N**

- Input: `arr=[1,2,4,5], n=5`
- Output: `3`

**25. Count Occurrences of Each Character in String**

- Input: `s="hello"`
- Output: `h=1, e=1, l=2, o=1`

**26. Find Longest Word in a Sentence**

- Input: `"I love programming"`
- Output: `"programming"`

**27. Check if Array is Sorted**

- Input: `arr=[1,2,3,4,5]`
- Output: `"Yes"`

**28. Find Common Elements in Two Arrays**

- Input: `arr1=[1,2,3], arr2=[2,3,4]`
- Output: `[2,3]`

**29. Flatten a Nested List**

- Input: `[[1,2],[3,4],[5]]`
- Output: `[1,2,3,4,5]`

**30. Find Pair of Numbers that Add Up to Target**

- Input: `arr=[1,2,3,4], target=5`
- Output: `(1,4) or (2,3)`

## 🔴 Level 4 — Medium (IBM Exam Bonus Level)

**31. Find Longest Substring Without Repeating Characters**

- Input: `s="abcabcbb"`

**32. Count Pairs with Given Sum**

- Input: `arr=[1,2,3,4,5], sum=5`

**34. Check if Brackets are Balanced**

**35. Find All Duplicates in Array**

- Input: `arr=[1,2,3,2,4,3]`
